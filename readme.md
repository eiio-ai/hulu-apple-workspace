## 🚀 部署方式

### 方式一：本地使用（最简单）

1. 将整个文件夹保持完整
2. 双击 `index.html` 用浏览器打开
3. 所有数据存储在浏览器本地，断网也能用

> ⚠ 注意：本地文件方式不支持 PWA 安装到桌面，需要通过 HTTP 服务器访问才能安装

### 方式二：本地服务器（支持 PWA 安装）

#### Windows

```bash
# 进入项目目录
cd "C:\Users\你的用户名\Desktop\全能自我管理｜求职+减脂+英语+记账+变美计划"

# 用 Python 启动本地服务器
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080`

#### Mac

```bash
cd ~/Desktop/全能自我管理｜求职+减脂+英语+记账+变美计划
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`

### 方式三：GitHub Pages 部署（推荐，支持手机安装）

1. **创建 GitHub 仓库**
   - 登录 [github.com](https://github.com)
   - 点击右上角 `+` → `New repository`
   - 仓库名随意（如 `hulu-apple-workspace`）
   - 选择 `Public`（公开）
   - 点击 `Create repository`

2. **上传文件**
   - 在仓库页面点击 `uploading an existing file`
   - 将文件夹内所有文件拖入（index.html、manifest.json、service-worker.js、所有图标文件）
   - 点击 `Commit changes`

3. **开启 GitHub Pages**
   - 进入仓库 `Settings` → 左侧 `Pages`
   - `Source` 选择 `Deploy from a branch`
   - `Branch` 选择 `main`，文件夹选 `/ (root)`
   - 点击 `Save`
   - 等待 1-2 分钟，页面顶部会显示访问地址：`https://你的用户名.github.io/hulu-apple-workspace/`

4. **访问应用**
   - 用浏览器打开上面的地址
   - 应用即可正常使用，支持 PWA 安装

## 📱 安装到桌面/手机主屏

### Android 手机（Chrome 浏览器）

1. 用 Chrome 打开应用网址
2. 点击浏览器菜单（右上角 ⋮）
3. 选择「添加到主屏幕」或「安装应用」
4. 确认安装，桌面会出现红苹果图标
5. 点击图标即可像原生 APP 一样打开，独立窗口运行

### iPhone / iPad（Safari 浏览器）

1. 用 Safari 打开应用网址
2. 点击底部分享按钮（⬆️ 方框图标）
3. 选择「添加到主屏幕」
4. 点击「添加」，桌面出现红苹果图标
5. 点击图标即可全屏打开使用

> ⚠ iOS 必须用 Safari 才能添加到主屏幕

### 电脑端（Chrome / Edge）

1. 用 Chrome 或 Edge 打开应用网址
2. 地址栏右侧会出现「安装」图标（📥）
3. 或点击浏览器菜单 → 「安装呼噜苹果工作台」
4. 安装后可在桌面/开始菜单找到应用图标
5. 双击图标以独立窗口打开，无需打开浏览器

## 💾 数据备份与迁移

### 导出备份

1. 进入「我的」→「💾 数据备份与导入」
2. 点击「📤 导出JSON备份」
3. 浏览器自动下载 `呼噜苹果_备份_日期.json` 文件

### 导入恢复

1. 进入「我的」→「💾 数据备份与导入」
2. 点击「📥 导入JSON恢复」
3. 选择之前导出的 JSON 文件
4. 确认导入，全部数据恢复

### 电脑 → 手机迁移

1. 在电脑上导出 JSON 备份文件
2. 将 JSON 文件传到手机（微信/邮件/云盘/U盘）
3. 在手机上打开应用，进入数据备份模块
4. 点击「导入JSON恢复」，选择文件
5. 全部数据迁移完成

## 🔧 技术说明

- **纯前端实现**：HTML + CSS + JavaScript，无后端依赖
- **数据存储**：浏览器 localStorage，不联网不上传任何服务器
- **离线可用**：Service Worker 缓存全部资源，断网仍可使用
- **版本更新**：联网时自动检测新版本，合并新增图文笔记，旧笔记永久保留
- **响应式设计**：手机优先，电脑端自适应
- **PWA 配置**：支持安装到桌面、独立窗口运行、离线使用
